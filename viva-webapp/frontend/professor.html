Excel tip
Long roll numbers (e.g. 202312345678) get converted to scientific notation by Excel (7.15523E+11), which loses digits. To prevent this: select the roll_number column → Format Cells → Text → then save as CSV. Or open the CSV in Notepad first to verify the numbers look correct.
